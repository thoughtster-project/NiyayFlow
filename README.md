# NiyayFlow (นิยายโฟลว์)

เครื่องมือช่วยเกลาสำนวนนิยายส่วนตัวแบบ Progressive Web App (PWA) และ Desktop
รองรับแนวกำลังภายใน แฟนตาซี และโรมานซ์/อีโรติก (NC Mode) ด้วยสถาปัตยกรรม Dual-Engine ไม่ติดขัดเรื่อง Safety Filter

## วิธีติดตั้งและรันบนเครื่องคอมพิวเตอร์

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. รันแอปพลิเคชันสำหรับทดสอบ
npm run dev
```

เปิดบราวเซอร์ที่ `http://localhost:5173`

## ฟีเจอร์เด่น
1. **Dual-Engine:** สลับใช้ Gemini (บททั่วไป) และ Ollama Local / OpenRouter (ฉาก NC/โรมานซ์)
2. **Granular Diff View:** เลือกยอมรับหรือคงร่างเดิมทีละประโยค
3. **Lorebook:** คลังศัพท์ตัวละคร/วิชา ล็อกคำเฉพาะไม่ให้ AI เปลี่ยน
4. **Version History:** บันทึกประวัติการเกลาย้อนหลัง คืนค่าได้ตลอดเวลา
5. **Zen Focus Mode:** พิมพ์งานคลีนตา ตัดสิ่งรบกวน
